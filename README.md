## 📦 Установка
### Установка из репозитория
```bash
# Клонируйте репозиторий
git clone https://github.com/MMagomedov284/frontend-project-46.git
cd frontend-project-44

# Установите зависимости
make install

# Установите пакет глобально
sudo npm link
```
